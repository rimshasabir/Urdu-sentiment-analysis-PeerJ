Deep Learning Tchniques for Contextual Sentiment Analysis in Urdu with Negation Awareness

Description
This repository contains the code and resources for the paper "Deep Learning Techniques for Contextual Sentiment Analysis in Urdu with Negation Awareness". It implements and compares a fine-tuned XLM-RoBERTa model and a hybrid BiLSTM model with rule based negation handling for ternary sentiment analysis (Positive, Negative, Neutral) on Urdu political tweets.
Urdu Sentiment Analysis with Negation Handling
This part contains the implementation for the paper "Deep learning techniques for contextual sentiment analysis in Urdu with negation awareness". The system implements a hybrid approach combining rule-based negation detection with deep learning models for enhanced sentiment analysis in Urdu in 3 steps.
These steps addresses the challenge of negation handling in Urdu sentiment analysis through a 3-step process:

1.	Negation Detection: Identifies negation scopes in Urdu text and adjusts XLM-R embeddings
2.	Data Augmentation: Generates synthetic negated examples to improve model robustness
3.	Hybrid Model: Combines XLM-R transformer features(embeddings) with explicit negation signals

XLM-RoBERTa Fine-tuning for Urdu Sentiment Analysis
This module fine-tunes the pre-trained multilingual transformer model `cardiffnlp/twitter-xlm-roberta-base-sentiment` for Urdu sentiment classification. The model is adapted to classify Urdu text into three sentiment categories: Positive, Negative, and Neutral.
Model Architecture
Base Model: `twitter-xlm-roberta-base-sentiment` (XLM-RoBERTa variant)
Classification Head: Linear layer with 3 output units (positive/negative/neutral)
Input Processing: Tokenization with XLM-R tokenizer, max length 256 tokens
Optimization: AdamW optimizer with linear learning rate schedule

Hyperparameter Optimization
To ensure optimal model performance, we conducted a systematic hyperparameter search for both the fine-tuned XLM-R model and the hybrid model. For each architecture, we performed a two-stage optimization:
Batch Size Optimization: Models were trained with batch sizes of 8, 16, 32, 64, 80, and 128 for 10-15 epochs. Performance was evaluated using Macro F1-Score and validation accuracy.
Learning Rate Optimization: Using the optimal batch size, we tested learning rates from 5e-3 (very high), 3e-4(high), 5e-5(moderate), 2e-5(low), and 1e-5 (very low) to identify the value providing stable convergence and peak performance.
The optimization process revealed that:
XLM-R Model: Optimal batch size = 64, Optimal learning rate = 5e-5
Hybrid Model: Optimal batch size = 16, Optimal learning rate = 5e-5
The hyperparameter optimization code is provided in the supplementary repository, allowing researchers to reproduce our experiments or conduct their own parameter searches.

Code Information
preprocess.py: Script for preprocessing and tokenizing Urdu text.
The negation handling pipeline consists of three sequential modules:

Step1-negation-detection.py
Purpose: Detects negation scopes in Urdu text and adjusts XLM-R embeddings for affected sentiment words.
Key Functions:
‘NegationDetector.get_negation_scopes()’: Identifies negation words and their syntactic scopes
‘NegationDetector.get_negation_delta()’: Computes semantic shift vectors for negated phrases
‘NegationDetector.adjust_embeddings()’: Modifies XLM-R embeddings for tokens within negation scopes
Outputs: Adds ‘has_negation’ (binary flag), ‘negation_scopes’ (token ranges), and ‘xlmr_embeddings_negadjusted’ (modified embeddings) columns.

Step2-data-augmentation.py
Purpose: Generates synthetic training examples by strategically inserting negation words.
Key Functions:
‘DataAugmenter.create_negated_version()’: Creates negated variants of positive/negative sentences
‘DataAugmenter.augment_row()’: Identifies sentiment words for negation insertion
‘DataAugmenter.clean_data()’: Prepares data for augmentation
Outputs: Augmented dataset with balanced class distribution and increased negation examples.

Step3-hybrid-model.py
Purpose: Implements and trains a hybrid neural network combining XLM-R features with explicit negation signals.
Key Components:
HybridModel class: Main model architecture with dual-input design
Transformer pathway: XLM-RoBERTa for contextual embeddings
Negation pathway: Dense network processing explicit negation features
Combined classifier: Integrated architecture with optimized hyperparameters
Outputs: Trained model weights, training logs, and evaluation metrics.

train_xlmr.py:
Key Components:
UrduSentimentDataset: PyTorch Dataset class for Urdu text
XLMRSentimentTrainer: Main training pipeline class
‘train_epoch()’: Single epoch training with gradient clipping
‘evaluate()’: Comprehensive evaluation with metrics (Accuracy, F1, Precision, Recall)
‘predict()’: Inference function for new texts
Features:
Automatic label mapping from dataset
Stratified train/validation/test splitting
Gradient clipping for training stability
Early stopping based on validation F1-score
Complete model saving with label mappings
GPU/CPU device detection and optimization

Usage Instructions
1.	Install dependencies: `pip install -r Requirement.txt`
2.	Download the Dataset: Download the Kaggle dataset and place `urdu_tweets.csv` in `data/raw/`.
3.	Run preprocessing: `python preprocess.py`
To preprocess the raw data:
```bash
python preprocess.py --input data/raw/urdu_tweets.csv --output data/processed/processed.csv
4.	To train the XLM-R model: 
python train_xlmr.py --input data/processed/urdu_tweets.csv --output_dir models/xlmr_model
5.	To train the Hybrid model: Run individual steps. Following are the steps details:
5.1.	Step 1: Negation Detection
python Step1_negation_detection.py \
  --input data/raw/urdu_tweets.csv \
  --output data/processed/dataset_with_negation.csv
5.2.	Step 2: Data Augmentation 
python Step2_data_augmentation.py \
  --input data/processed/dataset_with_negation.csv \
  --output data/augmented/augmented_dataset.csv \
  --analyze
5.3.	Step 3: Hybrid Model Training
python Step3_hybrid_model.py \
  --input data/augmented/augmented_dataset.csv \
  --output_dir models/hybrid_model \
  --test_split 0.2
